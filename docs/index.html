Free open source tool

sla-recalc

Recompute first response and resolution SLAs from a raw ticket CSV using your own business hours, holidays and per priority targets, and see exactly where the helpdesk dashboard number is wrong.

View source on GitHub

What it does

First response and resolution times recomputed in business minutes from the raw ticket export
Configurable business hours per weekday, a holiday list, and a fixed UTC offset you control
Per priority first response and resolution targets, with a breach flag on every ticket
Business minutes printed beside calendar minutes per ticket, so a weekend wait that a dashboard counts as a breach becomes a number you can point at
Markdown summary with breach counts and rates by priority and by team

Install and usage

Requires Node.js 20 or later. There are no dependencies to install.

git clone https://github.com/aamirtechs/sla-recalc.git
cd sla-recalc
node src/cli.js --input examples/tickets.csv --config examples/config.json --out out.csv --report report.md

Timestamps are ISO 8601 and are interpreted in the single fixed offset from the config, so the same input and config always give the same answer on any machine. Tickets with an empty first reply or resolution time are excluded from that measure instead of being counted as breaches.
